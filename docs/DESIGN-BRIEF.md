# 소리책 디자인 브리프 (v1.32.0 전면 개편, 2026-10-14)

- **도메인**: 온디바이스 TTS 자막 리더(오디오북) · 안드로이드 · 한 손 조작·장시간 청취
- **타겟**: 한국어 장편(소설·역사물) 청취자. 밤에 화면을 끄고 듣는 시간이 길다
- **톤 키워드 3**: 차분함 · 몰입 · 종이책의 따뜻함
- **다크 우선순위**: 높음 — 밤 청취가 주 사용 장면. AMOLED 기기(Galaxy S25 Ultra) → **완전 검정(OLED)** 테마가 배터리 축
- **D1 3안 (theme-recipes 분기 공식)**
  - A 정석 — 기존 인디고 브랜드를 다듬은 중성 회색 + 인디고 (사용자 2026-07-08 「샛노랑 촌스럽다 → 인디고」 연속성)
  - B 차분 — 세피아 종이(크림 바탕·잉크 갈색·호박 하이라이트)
  - C 개성 — 한밤(진남색 + 은은한 금빛 하이라이트)
- **채택(자율 모드, 사유 1줄)**: A 를 브랜드 기본으로, B·C 는 버리지 않고 **사용자가 고르는 읽기 테마**(세피아·다크·OLED 블랙)로 흡수 — 리더 앱은 «한 테마 강요»보다 «읽는 환경 선택»이 관습이고, OLED 블랙은 배터리 요구와 직결된다
- **결정론 게이트**: RN 이라 CSS design-gate 대신 `src/__tests__/themeContrast.test.ts` — 모든 테마의 본문·보조·버튼 글자 대비 ≥4.5, 흐린 이웃 자막 ≥3.0
