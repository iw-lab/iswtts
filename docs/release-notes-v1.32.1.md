## 소리책 v1.32.1 — PDF 띄어쓰기 · 목차 고침

- **PDF 가져오기에서 글자마다 띄어지던 문제**(「소 리 책 PDF 가 져 오 기」)를 고쳤습니다. 글자 사이 실제 간격을 보고 원문 띄어쓰기대로 잇습니다 — 낭독이 한 글자씩 끊기지 않아요. (이미 가져온 PDF는 지우고 다시 가져오면 깨끗해집니다.)
- 마크다운 책에서 장면 구분선(`* * *`·`---`)이 목차와 「지금 읽는 장」에 「* *」로 나오던 것을 고쳤습니다(글자가 없는 줄은 제목으로 안 봅니다).

v1.31 이하에서 바로 올리시는 분은 아래 v1.32.0 변경도 함께 들어 있습니다.

## 소리책 v1.32.0 — 목소리 안정화 · 배터리 절약 · 전면 새 디자인

### 🎙 목소리 안정화 (고품질 오프라인)
- **같은 문장은 언제 들어도 같은 목소리** — 문장마다 고정 시드로 합성합니다. 일시정지·되감기·배속 변경 뒤 다시 만들어져도 목소리가 바뀌지 않아요.
- **들쭉날쭉한 음량을 고르게** — 문장 사이 음량 흩어짐을 실측 7.1dB → 1.1dB(표준편차 1.30 → 0.20dB)로 줄였습니다. 지문↔대사 화자가 바뀔 때 소리가 튀지 않아요(화자 10명 모두 같은 크기로). 클리핑 0.
- 발음 교정: 「문자」[문짜] · 「나랏일」[나란닐] · 「옛이야기」[옌니야기] · 「성 밖」(된소리 방지) — 유튜브 낭독에서 사람 귀로 확인된 것만, 자막 글자는 그대로.
- 마크다운(.md) 책의 `#`·`>`·`**` 기호가 더 이상 자막·낭독에 나오지 않습니다(기존 책도 다시 열면 자동 정리).
- 설정 > 낭독 > 「음성 안정화」로 켜고 끌 수 있어요(기본 켜짐, 추가 배터리 없음).

### 🔋 배터리
- **재생 중 화면을 강제로 켜 두지 않습니다** (가장 큰 원인이었어요). 화면이 꺼져도 낭독은 계속됩니다. 화면을 켜 두고 싶으면 플레이어의 ☀ 버튼 또는 설정 > 화면.
- 화면이 꺼진 동안 앱을 깨우는 횟수를 줄였습니다(오디오 상태 알림 주기 80→250ms, 쉬고 있는 재생기는 아예 잠듦).
- PDF용 숨은 브라우저가 앱 내내 떠 있던 것을 PDF를 가져올 때만 뜨게 바꿨습니다.
- **검정(절전) 테마** — OLED 화면에서 화면 전력을 가장 적게 씁니다.
- **취침 타이머** 🌙 — 15/30/45/60/90분 또는 「이 문단이 끝나면」. 화면이 꺼져 있어도 정확히 멈춥니다(문장이 끝나는 자리에서).

### ✨ 새 디자인과 기능
- 서재: **이어 듣기** 카드(한 번 누르면 바로 재생) · 최근에 들은 순 · 남은 시간 표시 · 이름 바꾸기 · 처음부터 듣기 · **글 붙여넣기**(복사한 글을 바로 듣기) — 입력 창은 키보드 위로 올라와 버튼이 가리지 않아요. 업데이트 전에 읽던 책도 바로 「이어 듣기」에 뜹니다.
- 플레이어: **목차와 찾기**(장 제목으로 이동 · 낱말로 문장 찾기) · 지금 읽는 장 표시 · 남은 시간 · 새 아이콘
- 설정: 테마 5종(자동·밝게·종이·어둡게·검정) · 섹션 정리 · 배터리 진단 · 업데이트 직접 확인

### 실측으로 확인했지만 넣지 않은 것 (정직하게)
- 합성 단계 수를 줄이면 배터리가 10~25% 줄지만, 잡음이 4단계 5배·3단계 11배로 늘어 귀에 들려서 넣지 않았습니다.
- 「말끝 뒤 짧은 소리 지우기」를 만들었다가, 그게 「-었다」의 진짜 마지막 「다」라는 걸 실측으로 확인하고 폐기했습니다(동사 끝이 사라질 뻔).
