## 소리책 v1.33.0 — 유튜브 두 목소리 추가 (깨짐 방지)

설정 > 목소리(고품질 오프라인) 맨 위에 두 목소리가 생겼습니다.

- **6.25 여자 목소리 (맑게)** — 「6.25·태평양전쟁」 유튜브 낭독 목소리(화자 1). 배속하면 「ㅅ·ㅆ·ㅊ」 쉿 소리가 튀던 것을 눌렀습니다(치찰음 누르기 + 터지는 자음 누르기).
- **삼국지 남자 목소리 (안 깨지게)** — 「쉬운 삼국지」 유튜브 낭독 목소리(화자 6). 배속할 때 「딱·툭」 하고 깨지던 터지는 자음(ㄱ·ㄷ·ㅂ)을 눌렀습니다.

유튜브 제작에 쓰는 처리를 그대로 앱에 옮겼습니다(같은 문장 8개로 맞춰 봄: 차이 −57dB 아래 · 길이 그대로 → 자막·하이라이트 그대로). 고역(≥5kHz)만 다듬어 말소리 몸통은 그대로이고, 문장마다 한 번만 처리해 배터리는 거의 그대로입니다.
대사를 다른 목소리로 읽기(멀티보이스)에서도 이 두 목소리를 고를 수 있습니다.
